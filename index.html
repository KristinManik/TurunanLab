Ringkasan rumus turunan

Kenali aturan dasarnya sebelum menghitung.

Aturan 1

Konstanta

d/dx (c) = 0

Turunan bilangan tetap adalah nol.

Contoh: f(x) = 7 → f′(x) = 0

Aturan 2

Aturan pangkat

d/dx (xⁿ) = n xⁿ⁻¹

Kalikan dengan pangkat, lalu kurangi pangkat satu.

Contoh: x⁵ → 5x⁴

Aturan 3

Konstanta pengali

(c f)′ = c f′

Konstanta di depan fungsi tetap dikalikan.

Contoh: 4x³ → 12x²

Aturan 4

Penjumlahan / pengurangan

(f ± g)′ = f′ ± g′

Turunkan setiap suku satu per satu.

Contoh: x² + 3x → 2x + 3

Aturan 5

Perkalian fungsi

(fg)′ = f′g + fg′

Turunan fungsi pertama kali fungsi kedua, ditambah fungsi pertama kali turunan fungsi kedua.

Aturan 6

Pembagian fungsi

(f/g)′ = (f′g − fg′)/g²

Turunan atas kali bawah, dikurangi atas kali turunan bawah, dibagi bawah kuadrat.

Aturan 7

Aturan rantai

d/dx f(g(x)) = f′(g(x)) · g′(x)

Turunkan fungsi luar, pertahankan fungsi dalam, lalu kalikan turunan fungsi dalam.

Contoh: (2x + 1)³ → 6(2x + 1)²

Aturan 8

Trigonometri dasar

(sin x)′ = cos x
(cos x)′ = −sin x

Ingat juga: (tan x)′ = sec² x.

Aturan 9

Eksponen dan logaritma

(eˣ)′ = eˣ
(ln x)′ = 1/x

Untuk ln x, domain fungsi adalah x > 0.

Kalkulator turunan

Masukkan polinomial dan kalkulator akan menurunkan setiap suku.

Masukkan fungsi f(x)

Format sederhana: koefisien dan pangkat, gunakan x. Contoh: 3x^3 - 2x^2 + 4x - 7.

Hasil turunan akan muncul di sini.

Kalkulator ini mendukung polinomial: konstanta, x, dan pangkat bilangan bulat nonnegatif. Belum mendukung pecahan fungsi, trigonometri, atau fungsi bersarang.

Contoh langkah

Fungsi awalf(x) = 3x³ − 2x² + 4x − 7
Turunkan tiap suku3x³ → 9x²
−2x² → −4x
4x → 4
−7 → 0
Gabungkan hasilf′(x) = 9x² − 4x + 4
